# Security

These applications are previews without an independent security audit.
Read the product-specific format, architecture and security documents before
relying on a protection claim. Open source, automated checks and signed
distribution packages are not guarantees of safety.

Testing to date has been carried out by the KryptoCoreLabs maintainers, locally
and through automated CI. No independent security audit has been completed.
We welcome community testing, code reviews and scrutiny of our security
assumptions. Please use synthetic data and report suspected vulnerabilities
privately through the project's security-reporting channel.

Report suspected vulnerabilities privately through
[GitHub Private Vulnerability Reporting](https://github.com/kryptocorelabs/vault-source/security/advisories/new).
If that route is unavailable, open an issue asking for a private contact and
keep technical details for the private discussion. Include the affected version
or commit, impact and steps using synthetic data. Never attach real credentials,
vaults, identities, contact codes or emergency sheets.

First-party Vault, the Firefox extension, the Windows native host, and the
format and release workflows are in scope. See the [Vault threat model](apps/vault/THREAT_MODEL.md)
for the trust boundaries. The [project response and disclosure policy](https://github.com/kryptocorelabs/kryptocore/blob/main/SECURITY.md#response-and-disclosure)
defines response targets, private coordination and publication.
