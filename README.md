# KryptoCore Vault source

Private Windows Vault application and Firefox extension workspace.
The public [Vault release repository](https://github.com/kryptocorelabs/vault)
hosts downloads and release notes. The underlying
[KryptoCore library](https://github.com/kryptocorelabs/kryptocore) is open source.

- [Vault development guide](apps/vault/README.md)
- [Vault CI and build verification](apps/vault/CI.md)
- [Security and recovery](apps/vault/SECURITY.md)

Test with synthetic vaults. Keep user vaults and signing credentials local.
