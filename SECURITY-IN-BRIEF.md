# Security in 30 seconds

KryptoCore helps keep locked files private and detects changes to encrypted
contents. Each app has additional limits.

- **Keys matter.** Weak passwords can be guessed. A stolen key can unlock data.
  Changing a password does not revoke old copies.
- **Devices matter.** Malware can read unlocked data. Encryption and signatures
  do not make files virus-free.
- **Backups matter.** Keep dated copies and matching recovery credentials
  separately. Test recovery on a copy. Lost files or keys may mean lost data.

These are previews, tested by maintainers and automated checks. No independent
security audit yet. Community review is welcome.
