# Code of Conduct

KryptoCore welcomes contributors of all backgrounds and experience levels.
This policy applies to project issues, pull requests, reviews, and discussions.

- Give feedback about the work and explain disagreements without personal attacks.
- Respect other people's time, privacy, and boundaries.
- Harassment, discriminatory remarks, threats, and sharing someone's private
  information without consent are unacceptable.

Report harmful behavior through [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Send the report to the repository maintainers if GitHub offers that option, or
use GitHub Support's private reporting form. Keep private details out of public
threads.

Maintainers may remove harmful content, close discussions, or restrict
participation according to the severity and repetition of the behavior.
